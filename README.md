# Personal Budget & Expense Tracker — Static Skeleton

## Project files
- `index.html` — the page structure and placeholder content.
- `style.css` — basic styling using element, class, and ID selectors.

## How to view the project
1. Extract the ZIP file.
2. Open the `budget_tracker` folder.
3. Double-click `index.html` to open it in your web browser.

## DevTools practice
1. Open the page in your browser.
2. Right-click the page and choose **Inspect**.
3. In the Elements panel, select the main heading or one of the sections.
4. In the Styles panel, temporarily change a CSS value, such as `background-color` or `font-size`.
5. Refresh the page to see that temporary DevTools changes are not saved.

## Note
This is intentionally a static HTML/CSS version. The form and button are visual placeholders and do not save or calculate expenses yet.
